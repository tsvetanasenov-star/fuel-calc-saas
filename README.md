# Гориво+

Модерен Micro SaaS калкулатор за разход на гориво и разходи за пътуване. Всички текстове са на български език.

## Функционалности

- **Разход на 100 км** – среден разход, цена за 1 км, цена за 100 км и обща стойност на зареденото гориво.
- **Пътни разходи** – обща цена на пътуването, опция отиване/връщане ×2 и разделяне между пътници.
- **Пробег с налично гориво** – пробег от налични литри или от определен бюджет.
- **Сравнение на автомобили / горива** – годишни и месечни разходи за два варианта, спестена сума и процент.
- **Профили на автомобили** – запазване, редактиране и изтриване в `localStorage`.
- **История на изчисленията** – запазване, копиране на готов текст за споделяне и изчистване.
- Светла/тъмна тема, адаптивен дизайн и валидации срещу отрицателни числа и деление на нула.
- Всички парични стойности са в евро (€).

## Деплой

Приложението е статично (само Vite build) и може да се хоства без сървър.

### Vercel / Netlify

- **Framework preset:** Vite
- **Build command:** `npm run build`
- **Output directory:** `dist`
- **Install command:** `npm install`

Достатъчно е да свържете GitHub репозитория – всеки push към `main` ще пуска нова сборка.

### GitHub Pages

1. В `vite.config.js` добавете `base: '/ИМЕ-НА-РЕПОЗИТОРИЯ/'` (само ако сайтът е на подпът, напр. `https://username.github.io/gorivo-plus/`).
2. Изпълнете `npm run build`.
3. Публикувайте съдържанието на `dist` в клона `gh-pages` или настройте GitHub Action с `peaceiris/actions-gh-pages`.
4. В репозитория: **Settings → Pages → Source: Deploy from a branch → gh-pages / root**.

> За custom домейн добавете CNAME файл в `public/` или го задайте в настройките на съответната платформа.
